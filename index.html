Setup Printer XP

Driver yang dipakai

Gunakan arsip driver XP Printer yang sudah disimpan di folder project untuk install printer thermal kasir.

Download Driver XP
1
Install driver XP Printer

Extract file RAR, install driver sesuai OS, lalu restart browser kalau printer belum muncul.

2
Pilih ukuran kertas

Untuk printer kecil pilih 58 mm. Kalau struk lebar atau printer 80 mm, ubah di Edit Struk.

3
Set print dialog

Margins none/minimum, scale 100%, headers and footers off. Kalau kanan kepotong, turunkan scale ke 95%.

4
Test print

Tekan Test Print lalu pilih printer thermal XP/POS di dialog browser.
